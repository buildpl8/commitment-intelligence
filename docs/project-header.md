# Commitment Intelligence — Project Header

## Mission

Commitment Intelligence exists to help people understand the obligations, risks, patterns, and behavioral commitments hidden inside contracts.

## Product Thesis

Contracts are not just legal documents. They are maps of future behavior. They define who must do what, when, under what conditions, and with what consequences.

Commitment Intelligence turns those obligations into structured evidence so individuals, teams, and organizations can reason about them clearly.

## Initial Architecture

The system begins with four independently deployable boundaries:

- `web` — public-facing React application
- `portal` — Lucee application for future application workflows
- `worker` — Python service for future asynchronous processing
- `database` — PostgreSQL persistence layer

## Operating Principle

Architectural intent must exist before it can be preserved.

The repository foundation is therefore treated as a first-class deliverable.
